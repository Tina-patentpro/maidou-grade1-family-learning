# 麦岛小学一年级家庭学习 Skill 设计规格

日期：2026-08-30  
版本：方案 A2.1  
状态：书面规格已确认

## 1. 目标

创建一个本地 Codex Skill：`maidou-grade1-family-learning`，帮助家长结合麦岛小学一年级课表、学校实际教学进度和本地教材，为孩子提供低负担、重兴趣、可持续的家庭学习支持。

Skill 遵循以下顺序：

1. 课前激活已有经验；
2. 课堂学习由学校完成；
3. 家庭通过回忆、表达、操作和生活迁移进行简短连接；
4. 用形成性观察记录学习证据；
5. 只有经多情境验证和家长确认后，才建立“待发展点”；
6. 根据孩子表现和状态安排后续观察，而非机械重复训练。

Skill 的价值不是增加课程或练习量，而是帮助家长回答三个问题：

- 今天是否适合进行家庭学习活动？
- 如果适合，哪一个活动最有价值且负担最低？
- 孩子的理解、兴趣和独立性正在怎样变化？

## 2. 设计依据与约束

### 2.1 教育原则

- 以儿童发展、学校教学和家庭关系为中心，AI 仅提供支持。
- 预习是“激活经验和产生问题”，不是提前讲授新课。
- 复习采用低压力提取、表达和迁移，不采用机械刷题。
- 元认知通过成人示范、提示和逐步撤去支架形成，不要求一年级儿童独立执行复杂反思流程。
- 兴趣保护同时关注自主感、胜任感和亲子关系，不依赖积分、连续打卡或外部奖励。
- 游戏应是有学习目标、儿童有选择、成人轻度引导的活动，而不是练习题换皮。
- 学习评价用于调整支持方式，不用于排名、贴标签或预测长期能力。

### 2.2 政策边界

- 默认不生成书面家庭作业。
- 不生成周测、月测、模拟考试、分数、排名或计时竞赛。
- 不超越国家课程标准、教材内容或学校实际教学进度。
- 不把家庭活动描述成学校要求或教师布置的任务。
- 写字、书面练习和具体英语内容只有在学校明确布置或家长明确要求时才可生成。
- 家庭活动优先采用阅读、谈话、实物操作、观察、体育、艺术、劳动和社会实践。

参考依据：

- 教育部《义务教育课程方案和课程标准（2022年版）》
- 教育部《关于加强义务教育学校作业管理的通知》
- 教育部《关于进一步加强中小学日常考试管理的通知》（2025）
- EEF《Metacognition and Self-Regulated Learning》第二版（2025）
- EEF低年级读写、早期数学和小学科学指南及证据综述
- 自我决定理论教育干预元分析（2024）
- 引导式游戏系统综述与元分析（2022）

这些材料提供“最佳可能做法”，不能替代教师判断，也不能保证对单个儿童必然有效。Skill 必须根据实际使用反馈调整。

## 3. 范围

### 3.1 包含

- 读取本地课表和已确认教材索引。
- 接收家长提供的当日课堂进度、学校作业、孩子精力和兴趣。
- 生成零个或一个家庭活动。
- 生成下一上课日的一项可选课前激活活动。
- 记录结构化学习证据、兴趣信号和所需提示。
- 生成非评分式周度“学习故事”。
- 提醒家长材料缺失、进度不明或证据不足。
- 在需要时使用已有语音或转写能力支持朗读、复述和家长记录。

### 3.2 不包含

- 替代教师授课、提前系统讲授新课或自行推断课堂进度。
- 诊断学习障碍、注意力问题、语言障碍或其他医学与心理问题。
- 自动判定孩子“薄弱”“落后”或“完全掌握”。
- 自动向教师、学校或第三方发送数据。
- 自动创建日历提醒、连续打卡或学习排名。
- 在没有教材或学校材料时编造英语、地方课程、校本课程和劳动课程的具体教学内容。
- 长期保存儿童原始录音、视频或照片；除非家长针对单次操作明确要求。

### 4.2 信息优先级

发生冲突时按以下优先级处理：

1. 家长提供的教师当日通知或学校作业；
2. 家长确认的课堂实际进度；
3. 纸质教材照片及封面版本；
4. 已核实的本地电子教材；
5. 固定课表；
6. Skill 的一般活动建议。

课表只说明课程安排，不证明某一天实际教授了某一教材页。Skill 不得仅凭课表推断具体教学进度。

设计取舍：

## 6. 学习数据目录

数据保存在教育资料目录，而不是 Skill 安装目录：

```text
<PRIVATE_EDU_ROOT>/
├── 学习档案/
│   ├── student-profile.json
│   ├── current-progress.json
│   ├── learning-evidence.jsonl
│   ├── development-points.json
│   └── interest-profile.json
├── 每日学习卡/
└── 每周学习故事/
```

原则：

- `learning-evidence.jsonl` 只追加观察事件，保留证据来源。
- `development-points.json` 是经确认后的当前状态，不保存永久性儿童标签。
- `interest-profile.json` 记录近期偏好及有效活动形式，兴趣可以变化。
- 只保存完成个性化所需的最少数据。
- 不在 Skill 中保存班主任姓名等无关个人信息。

## 7. 每次调用的数据流

### 7.1 输入检查

Skill 首先检查：

1. 用户是在请求课前激活、课后连接、学习证据记录、周度总结，还是一般咨询；
2. 是否有可信的课堂进度或学校任务；
3. 孩子当前精力：充足、一般、疲劳；
4. 孩子当前意愿：愿意、犹豫、不愿意；
5. 家长可投入时间和可用材料；
6. 当天是否已经存在学校任务或家庭活动。

缺少信息时只询问会改变决策的一项关键信息。若孩子疲劳或不愿意，默认建议休息、自由阅读或非任务式亲子活动。

### 7.2 对齐与决策

Skill 将请求与课表、教材索引、课堂进度和已有学习证据对齐，然后作出以下选择之一：

- 不安排活动；
- 生成一个2—5分钟课前激活；
- 生成一个5—12分钟课后连接；
- 记录一次自然发生的学习证据；
- 建议家长继续观察，不立即干预；
- 对一个已确认的待发展点安排适应性复查。

### 7.3 输出格式

每日输出不超过以下内容：

```text
是否建议活动
依据：课堂进度、孩子状态、近期证据
唯一目标
活动方式与所需材料
家长可以说的第一句话
逐级提示：等待 → 轻提示 → 示范
结束信号
家长可选观察记录
```

不得同时安排多个学科补习。若存在学校明确作业，Skill 优先帮助家长降低执行摩擦，不额外叠加活动。

## 8. 预习—学习—复习模型

### 8.1 课前激活

- 时长2—5分钟，可跳过。
- 只选择下一个上课日的一门核心课程。
- 使用教材图片、生活物品、问题或故事激活已有经验。
- 允许留下疑问，不要求当场解决。
- 不讲授教材尚未学习的规则、算法或字词清单。

### 8.2 课堂学习

- 明确标记为学校职责和主要学习场景。
- 家庭 Skill 不生成替代课程。
- 家长输入的实际进度用于更新 `current-progress.json`。

### 8.3 课后连接

- 先连接情绪和经历，再连接知识。
- 采用“回忆或演示—轻提示—必要时示范—换情境尝试”的顺序。
- 每次只有一个学习目标。
- 以孩子解释、操作或应用作为主要证据，不以题量作为证据。
- 明确的疲劳、挫败或亲子冲突是立即结束信号。

## 9. 兴趣与儿童自主性

Skill 必须执行：

- 提供两到三种活动形式选择，但不制造过多选择负担。
- 允许孩子选择表达方式，如说、摆、画、演、唱或走动完成。
- 保证任务主要部分可完成，只设置一个适度挑战。
- 使用具体过程反馈，例如指出观察、策略、坚持或换方法。
- 不进行人格化表扬或负面判断。
- 不以积分、徽章、连续打卡、物质奖励作为默认机制。
- 每周收集一次儿童声音：喜欢什么、想停止什么、想探索什么。
- 连续两次出现抗拒时，暂停相应活动形式并重新评估原因。

引导式游戏至少包含：清晰目标、儿童主动选择、成人轻提示、简短回顾。自由游戏可以存在，但不被伪装成测评机会。

## 10. 分学科策略

### 10.1 语文

- 优先发展口语、看图讲述、共同阅读、朗读、词语理解和真实表达。
- 拼音、识字和写字严格跟随学校进度与教材位置。
- 写作先口头组织，再视学校要求进行短量书写。
- 不以孤立字卡数量替代阅读理解和语言交流。

### 10.2 数学

- 使用“实物—图示—符号”逐步建立表征联系。
- 关注数感、数量关系、空间、比较、组成与分解，而不只关注计算速度。
- 要求孩子说明“怎样知道”，允许多种正确策略。
- 在熟悉情境和变化后的情境各观察一次，避免把机械模仿当作理解。

### 10.3 科学

- 使用“观察—预测—操作—证据—解释”的短流程。
- 在真实情境中使用科学词语。
- 家庭实验必须低风险、材料简单，并由成人监督。
- 不把预先告诉结论当作探究。

### 10.4 道德与法治

- 以校园、家庭和同伴生活情境讨论为主。
- 不追求标准化背诵答案。
- 尊重学校课堂的价值引导，不虚构发生过的校园事件。

### 10.5 英语

- 当前没有完整可核实教材，不生成教材进度内容。
- 有学校材料时优先采用听说、动作和情境表达。
- 不默认安排抄写、单词测验或超前拼读。

### 10.6 音乐、美术、体育、劳动及综合实践

- 以参与、表现、创造、运动和生活能力为目标。
- 不纳入知识空白排名或周度学术纠错。
- 劳动活动采用适龄、安全、真实的家庭任务。

## 11. 学习证据模型

### 11.1 单次观察事件

每条事件包含：

```json
{
  "observed_at": "ISO-8601时间",
  "subject": "学科",
  "source": "教材页码或学校材料",
  "learning_target": "本次唯一目标",
  "observed_behavior": "孩子实际说了或做了什么",
  "support_level": "independent | light_prompt | modelled | not_observed",
  "representation": "oral | object | picture | symbol | real_context",
  "energy": "high | medium | tired",
  "affect": "engaged | neutral | reluctant | distressed",
  "possible_explanation": "concept | memory | language | attention | motor | unclear",
  "parent_confirmed": false
}
```

`possible_explanation` 是待验证假设，不是诊断。

### 11.2 发展状态

```text
初次接触 → 正在形成 → 提示下完成 → 独立完成 → 能够迁移 → 延迟后稳定
```

状态只能根据证据更新：

- 单次错误只保留为观察事件；
- 至少两个不同情境出现同类困难，并经家长确认，才建立待发展点；
- 单次独立完成不能标记为稳定；
- 在变化情境中独立完成可以标记为能够迁移；
- 间隔后的自然观察仍能完成，才标记为延迟后稳定。

### 11.3 适应性复查

- 示范后仍困难：等待相关课堂教学后再观察；
- 轻提示完成：通常1—3天后换一种表达形式；
- 独立完成：通常3—7天后换生活情境；
- 能够迁移：通常1—2周后自然抽查；
- 延迟后稳定：归档，不再主动训练。

这些是建议窗口，不是自动截止日期。课堂进度、孩子状态和自然使用机会优先。

## 12. 与课表结合的默认节奏

课表只用于选择候选学科：

- 周一：共同阅读或休息；如有精力，可激活周二数学或阅读。
- 周二：数学或阅读二选一，不叠加英语和劳动任务。
- 周三：优先自然科学观察或看图表达。
- 周四：根据本周证据在语文、数学中二选一，也可以不安排。
- 周五：儿童作品、故事、歌曲或发现展示，不集中补弱项。
- 周末：最多一次家庭综合活动；学习档案整理由家长单独完成。

任何一天如有学校作业、明显疲劳、情绪不佳或家庭时间不足，默认节奏自动让位。

## 13. 周度学习故事

周报不使用分数、红黄绿排名或完成率排行榜。内容包括：

- 本周学校实际进度；
- 孩子愿意分享的一个亮点；
- 独立性或策略上的一个变化；
- 已稳定的学习证据；
- 最多两个需要继续观察的待发展点；
- 最有效和最无效的活动形式；
- 孩子的原话或选择；
- 下周一个家庭支持重点；
- 建议减少或停止的内容。

周报面向家长，不要求孩子阅读，也不作为奖惩依据。

## 14. 异常与停止条件

- 教材版本不明：停止生成具体页码活动，请家长核对。
- 课堂进度不明：仅提供共同阅读、生活观察或一般性亲子活动。
- 本地文件缺失或无法读取：明确列出缺失文件，不猜测内容。
- 输入与教材冲突：展示冲突并优先采用家长确认的学校信息。
- 孩子不愿意或明显疲劳：停止学科活动，不追问原因。
- 连续出现同类困难：记录证据并建议家长向教师了解课堂表现，不作诊断。
- 涉及安全、健康或心理风险：停止教育建议并提示寻求相应专业支持。

## 15. 隐私与权限

- 所有资料默认仅保存在本机。
- 未经明确授权不上传教材、儿童作品、录音、照片或学习档案。
- 不自动访问学校账号、家长群或第三方服务。
- 不自动发送任何消息。
- 原始语音如仅用于转写，默认在获得文本后不纳入长期档案。
- 删除或覆盖学习档案属于单独操作，执行前需要明确确认。

## 16. 测试与验收

### 16.1 结构验证

- `quick_validate.py` 通过 Skill 名称、frontmatter 和占位符检查。
- `SKILL.md` 能明确路由到各 reference。
- 两个脚本能处理合法输入，并拒绝缺少关键字段或非法状态值。

### 16.2 行为场景

至少验证：

1. 周一晚有课堂进度且孩子有精力：只生成一个周二课前激活。
2. 周二已有学校作业：不增加第二项学术任务。
3. 孩子表示疲劳：输出休息建议而非学习活动。
4. 单次数学错误：只记录观察，不建立待发展点。
5. 两个情境出现同类困难但家长未确认：仍不建立待发展点。
6. 家长确认后：建立待发展点并给出非机械复查窗口。
7. 英语教材缺失：不生成具体单元内容。
8. 写字请求超出学校进度：拒绝超前并请求课堂位置。
9. 音乐、美术、体育或劳动：不生成知识空白排名。
10. 周报：无分数、排名、负面标签或完成率压力。
11. 孩子连续两次抗拒同一活动形式：暂停该形式并调整兴趣档案。
12. 教材页码与家长提供的学校材料冲突：明确提示并要求确认来源。

### 16.3 成功标准

首轮试运行两周后，同时检查：

- 家庭活动没有明显增加书面作业负担；
- 每次输出最多一个学习目标；
- 家长每天提供信息和记录的时间保持简短；
- 孩子的参与意愿没有持续下降；
- Skill 能区分错误、疲劳、语言理解和概念困难；
- 待发展点有可追溯证据并经过家长确认；
- 活动与学校实际进度一致；
- 家长认为周报能帮助下一周作出减量或支持决策。

如兴趣下降、亲子冲突增加或记录负担过高，即使知识正确率提高，也视为设计未通过，需要减量或暂停。

## 17. 实施边界与顺序

书面规格确认后，下一阶段只编写实施计划。实施计划获准后再按以下方向执行：

1. 使用 Skill 初始化工具建立最小目录；
2. 编写核心入口和必要 references；
3. 将课表人工校核结果写成结构化参考；
4. 为已确认教材建立可追溯索引；
5. 建立学习档案目录与空白初始数据；
6. 编写并测试两个确定性校验脚本；
7. 执行结构验证和十二个行为场景；
8. 生成一周示例但不自动启用日程或提醒；
9. 经家长验收后开始两周试运行；
10. 根据兴趣、负担和对齐情况决定继续、调整或暂停。

本规格不授权自动登录学校平台、发送消息、创建提醒、上传儿童数据或删除已有资料。
