# 家长支架：少帮一步，再慢慢放手

支架只为帮助孩子表达或操作已在学校学习、且本次唯一目标所需的内容；不借提示讲授新规则或抢先给出结论。家长先确认孩子愿意继续，且没有疲劳、痛苦或亲子冲突。

## 固定顺序

1. `等待`：提出一个清楚、短的问题或邀请后，至少等待数秒，让孩子观察、想一想、试一试。不要立刻重复问题、纠正或给答案。
2. `轻提示`：只把注意力拉回已有线索，例如指向图中两组物品、复述孩子刚才的话，或问“你想先从哪里开始？”。一次只给一个提示。
3. `示范`：仍卡住且孩子愿意时，做一个最小示范并说出思路，例如“我先把这两块分开看，所以看见……”。示范的是怎样想和怎样尝试，不是要求照抄标准答案。
4. `逐步撤去支架`：孩子成功一次后，下次先减少提示、留出更长等待，或请孩子自己选择第一步。不能因成人帮得快就固定替孩子完成。

把“卡住”说成学习中正常的暂停，例如“现在还没想好很正常，我们可以看一看、试一试，或者今天停在这里”。孩子拒绝、疲劳、痛苦或出现冲突时，停止而不是升级支架。

## 反馈方式

`反馈描述任务、策略或自我调节`，而非智力、天赋或人格。可说“你把苹果移动后看清了数量”“你发现图里少了一部分，又回去看了一次”“你说想休息，我们今天就停在这里”。避免“你真聪明”“这么简单还不会”“你不够认真”等评价。

## 四种短例子

- **口语表达**：看图后先等待；若孩子停住，轻提示“你先看到谁了？”；仍需要时家长示范一句“我看到小猫在……”，再邀请孩子接着说，不替孩子讲完整故事。
- **实物操作**：摆两堆纽扣后等待孩子比较；轻提示“要不要把它们排成一行？”；必要时示范把其中一堆排开，再让孩子自己说明看到的关系。
- **画图表达**：请孩子画出今天观察到的现象后等待；轻提示“你想先画你最记得的地方吗？”；必要时示范一个简单符号或箭头，不替孩子完成作品。
- **动作与走动**：请孩子用走几步或拍几下表达已学的节奏、方向或数量后等待；轻提示“我们先慢一点试一次”；必要时家长示范一个动作，再让孩子决定是否继续、换方式或停止。
