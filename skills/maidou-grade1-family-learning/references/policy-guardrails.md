# 政策、安全与权限边界

## 家庭作业与评价

- 默认不生成书面家庭作业。
- 不生成周测、月考、模拟考试、分数、排名或限时竞赛。
- 每次请求只生成零个或一个家庭学习活动，不同时进行多学科辅导。
- 课前预览仅用于可选的体验激活，不进行超前教学。
- 课后连接只围绕一个目标，可选回忆、表达、操作材料或迁移中的一种方式。
- 单次错误只是观察；只有在两个不同情境都出现后，且家长明确确认，才能记录为待发展点。
- 不诊断学习、注意力、语言、心理或医学状况。
- 英语、劳动、地方或校本材料缺失时，明确提示材料缺口，不编造内容。

## 儿童安全

- 孩子疲劳、拒绝、痛苦或出现亲子冲突时，立即停止学科活动。
- 教材版本不明时，停止生成具体页码活动，请家长核对。
- 课堂进度不明时，只提供共同阅读、生活观察或一般性亲子活动。
- 本地文件缺失或无法读取时，列出缺失文件，不猜测内容。
- 涉及安全、健康或心理风险时，停止教育建议，并提示家长寻求相应专业支持。

## 隐私与权限

- 儿童资料默认仅保存在本机；私有学习数据根目录只从被 Git 忽略的 `local-private-config.md` 或家长当次明确提供的位置解析，不在可发布文件中记录儿童姓名、别名、班级或本机绝对路径。
- 不上传或发送教材、儿童作品、录音、照片或学习档案，也不保留原始音频；如仅为转写而提供音频，获得文本后默认不将其纳入长期档案。
- 不自动访问学校账号、家长群或第三方服务，不创建提醒、外部消息、第三方连接或自动日程。
- 当前 Git 仓库是 Skill 的规范来源；不提交私有学习记录。
- 删除或覆盖学习档案是单独操作，必须重新获得明确确认后才可执行。
- 仅在已获得明确写入授权时，创建或维护私有学习目录（如学习档案、每日学习卡、每周学习故事）为 `0700` 或更严格；新建的档案、证据、学习卡和学习故事文件为 `0600` 或更严格。每次获授权写入后，检查目标的类型、所有者、非链接状态和权限模式；不得将已有的更严格权限放宽。此规则仅约束已获授权操作的权限保护，不授予任何额外的访问、创建、写入、覆盖或删除权限。

## 停止条件

- 学校确认的进度优先；不得仅凭课表推断已经教授的页码。
- 输入与教材冲突时，向家长展示冲突，并优先采用家长确认的学校信息，不得静默处理。
- 不自动发送、上传、提醒、删除或覆盖任何资料。
